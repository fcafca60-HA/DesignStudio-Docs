# Documentation publique — Jeedom Design Studio

Documentation utilisateur de la **V0.90.57-beta**. Le dépôt est public et ne contient aucun code source, clé HMAC ni configuration Jeedom personnelle.

GitHub Pages : **Settings → Pages → Deploy from a branch → main → /(root)**.

Liens du Market :

- https://fcafca60-ha.github.io/DesignStudio-Docs/fr_FR/
- https://fcafca60-ha.github.io/DesignStudio-Docs/fr_FR/changelog.html
- https://fcafca60-ha.github.io/DesignStudio-Docs/fr_FR/tutoriels.html

**Publication** : décompresser le ZIP Docs, puis déposer son contenu **à la racine du dépôt `DesignStudio-Docs` sur la branche `main`**. Le fichier `index.md` de ce package remplace la page de bienvenue temporaire.

Pour ajouter des vidéos, modifier uniquement `fr_FR/tutoriels.md` avec de véritables URL YouTube.
