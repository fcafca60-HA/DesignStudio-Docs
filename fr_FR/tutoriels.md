## Ajouter ses propres tutoriels YouTube

Pour publier une vidéo, ajoutez simplement dans ce fichier Markdown un lien explicite tel que `- [Importer un Dashboard Jeedom](https://www.youtube.com/watch?v=IDENTIFIANT_REEL)` une fois l'URL vérifiée. Publiez la modification sur `main` pour actualiser GitHub Pages.
